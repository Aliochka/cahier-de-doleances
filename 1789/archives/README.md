Les composants actifs sont décrits dans [le guide principal](../README.md). Les alias `data` et certains `.cache` renvoient à des emplacements uniques sous `../data/` et `../sources/`. Les données et manifestes conservent leurs octets et leurs chemins historiques de provenance ; les chemins de lecture sont traduits par le résolveur commun.

Les figures, vecteurs, transcriptions expérimentales et instantanés privés restent disponibles localement selon les exclusions Git d’origine. Une expérience peut également dépendre d’un cache temporaire ou d’un environnement qui était déjà absent avant ce déplacement ; aucune ressource manquante n’a été recréée ou téléchargée.
